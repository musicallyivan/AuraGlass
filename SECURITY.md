# Security policy

AuraGlass is a client-side Spicetify theme and does not have a dedicated security team or guaranteed response time.

Please do not report security vulnerabilities in public issues. Contact the repository maintainer privately through the contact options on [the maintainer's GitHub profile](https://github.com/musicallyivan), and include steps to reproduce and the potential impact. Avoid including real account credentials, tokens, or private user data.

If you cannot contact the maintainer privately, use GitHub's private vulnerability reporting option for this repository if it is enabled.
