# Contributing to AuraGlass

Thanks for helping improve AuraGlass. You can contribute by reporting a bug, proposing a feature, improving documentation, or submitting a pull request.

## Before you start

- Search the [existing issues](https://github.com/musicallyivan/AuraGlass/issues) to avoid duplicates.
- For bugs, include steps to reproduce, Spotify and Spicetify versions, and screenshots or console errors when useful. Remove personal information from logs.
- For ideas, explain the problem the change would solve and describe the result you would like.

## Pull requests

1. Fork the repository and create a branch for your change.
2. Keep the change focused and preserve the existing theme conventions.
3. Check JavaScript syntax and inspect the CSS for unintended layout changes.
4. Try visual changes in Spotify with Spicetify and include screenshots when they help reviewers.
5. Update the README or other documentation when behavior or setup changes.
6. Open a pull request with a concise summary, verification notes, and any relevant issue links.

There is no automated test suite currently. Please state clearly which checks you ran and which you could not run.

## Community

Be respectful and constructive. See the [Code of Conduct](CODE_OF_CONDUCT.md).
